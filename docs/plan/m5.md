## 子项

### M5.1 舞台栏：会话头 + 场景条 → 左侧可折叠竖栏 ✅

- 现状问题：`SessionView` 顶部会话头 + 场景条横条占约 110px 纵向；多角色时只显示
  主角色名 +「+N 同台」徽标，阵容不可见。
- 方案：新组件 `SessionRail.vue`（纯展示，emit 动作，API 留在会话视图——沿用 SceneBar
  组件契约）：会话信息（天/时/地 + 表情徽标）、**阵容逐行**（首字头像稳定取色 + 生成中/
  在场/候场状态 + 点击=点名发言，与输入区发言权 tabs 同一 `speaker` ref 天然双向同步）、
  场景垂直列表（切换/编辑/新建/分场/合场）、底部工具（导出剧本包/黑板/检查器 + 全局
  生成状态）。宽屏常驻可折叠（w-56 ↔ w-12 图标条，偏好 localStorage `huajing.railCollapsed`
  持久化）；窄屏（沿用 `max-[900px]:` 断点）转浮层抽屉 + 顶部细条（唤出钮 + 阵容头像组 +
  时间地点 + 面板开关）。`SceneBar.vue` 删除，职责并入 rail。
- 附带：`src/avatar.ts`（`initial`/`avatarStyle` 从 SessionView 提出共享——气泡与舞台栏
  同一取色）；阵容全员卡名装载 `loadCastNames`（原只取第一张卡）。

### M5.2 hover-3d + 设定集按世界分组 ✅

- **零依赖 3d**：`src/composables/useTilt.ts` 导出 `v-tilt` 指令（pointermove 写
  `--tilt-x/--tilt-y/--glow-x/--glow-y` 四个 CSS 变量；`prefers-reduced-motion` 或
  `pointer: coarse` 自禁用，**判定不缓存**——跟随系统动效开关即时生效）；`style.css`
  新增 `.tilt-card`（perspective + rotateX/Y + `::after` 跟手高光）。`main.ts` 全局注册。
- **世界分组**：后端新命令 `list_worlds`（扫 `DataHub/codex/*/`，类型计数走文件名前缀
  + grown.json 新实体键，世界钟读 world.json，主线看 worldline.lua 存在性——不解析 Lua）
  与 `codex_world_entities`（检查器同形实体投影抽 `entity_json` 助手复用，会话无关只读）。
- **资产页设定集页签重构**：顶层「选会话」改为**世界卡片网格**（v-tilt 卡：世界名/实体数/
  类型分布 chips/世界天数/主线徽标），点击下钻实体清单（搜索/刷新/世界包/ST 世界书导出/
  去会话检查器）；揭示集（会话视角数据）收敛到会话检查器。角色卡同步 `v-tilt`。

### M5.3 新建会话向导改版 ✅

- 后端：`new_session` 命令 + `world` 参数（校验 `DataHub/codex/<world>/` 存在才落
  `meta.world`，空/不存在回落 default——旧行为不变）；`NewSessionRequest` 加字段（23 处

- 前端：弹窗 `max-w-lg → max-w-3xl`；角色选择从 select+复选框升级为**卡片多选网格**
  （点击进/出阵容，aria-pressed）+ **有序阵容 chips**（序号即出场顺序，「设为主角色」
  调首位，「×」移出）；新增**设定集下拉**（`list_worlds`，实体数/天数/主线标注；主角色
  变更预填其卡声明的世界——仅当该世界真实存在）。`api.newSession` 透传 `world`。

### M5.4 设定集 char 条目自动绑定进身份层 ✅

- 语义：`type=char` 且能对上**阵容成员**的实体（id 后缀==目录名优先 → name/别名==卡显示
  名兜底；只认 canon）不再走普通激活——渲染卡以「自身设定」附录进**该角色自己**的 A3
  身份锚，并从她视角的 B3 激活池剔除（滞回也拉不回）；其他视角经在场/提及照常激活；
  NPC char 条目行为不变。
- 实现：`codex.rs` `ActivationContext` 加 `exclude_ids`（activate 渲染前剔除）+
  `Codex::render_for_viewer`（与 B3 同一渲染管线与 `secret_visible` 门控，Deep 档——
  秘密行只在 Deep 渲染，known_secrets 已按视角过滤）；`prompt.rs` `BuildInputs` 加
  `identity_extra`（拼进 A3，A 组超预算随 A3 先截断）；`commands.rs` `char_bindings`
  匹配 + 组装接线。
- 为什么数据在设定集不在角色卡：卡是 SillyTavern 兼容静态文本；secrets 知情门控、生命
  周期、正史增量（grown）、补全模板全绑在实体模型上，且世界跨会话共享——放设定集是对的，
  缺的只是绑定注入（design §6.3 已补小节）。
